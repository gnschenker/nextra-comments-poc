# Getting started

New platform engineers should be able to run a sample service locally, open a pull request, and request a preview environment on the first day.

## Accounts and access

Ask the current on-call to grant you the platform Git organization, the container registry, and the preview cluster. Access requests expire after 30 days if they are unused.

## Install the toolchain

1. Install the current LTS Node.js release.
2. Clone the sample service and run `npm install`.
3. Copy `.env.example` to `.env`.
4. Run `npm run dev` and confirm the health endpoint returns 200.

If the health endpoint fails, check that the local database migrated. The sample service uses SQLite so you do not need a shared database for this path.

## First pull request

Open a draft pull request against `main`. Add a reviewer from the platform rotation. Do not merge your own first change.

The sample service README lists the smoke checks the CI workflow runs. A red check on a draft is still useful. Treat it as a signal, not a release gate.
